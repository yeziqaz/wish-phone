# 模型与 API 分组设计（排版提案）

> 2026-10-31 · 还没写代码，先定排版
> 要解决的事：一个站子同时卖文字、生图、语音、视频；要能分开挑，还要能设「主模型」。

---

## 0. 一句话原则

**按「用途」分模型，不按「站子」分。**
站子只是地址 + Key；真正要选的是「聊天用哪个、生图用哪个、语音用哪个、视频用哪个」。

---

## 1. 数据上要加什么

```
ProviderModel
  kind: 'text' | 'image' | 'voice' | 'video'   ← 新字段，老数据默认 text

Bindings
  byKind: {
    text:  { providerId, modelId } | null      ← 聊天主模型
    image: { providerId, modelId } | null      ← 生图主模型
    voice: { providerId, modelId } | null
    video: { providerId, modelId } | null
  }
  characters: {
    [角色id]: { text?, image?, voice?, video? }  ← 专属覆盖，没填就跟随全局
  }
```

老数据迁移：现有模型全部当 `text`；现有默认模型搬进 `byKind.text`。

## 3. 服务商详情：模型按类型分标签

现在的模型折叠块改成四段：

```
模型 (6)
┌────────┬──────┬──────┬──────┐
│ 文字 4 │ 生图 2 │ 语音 0 │ 视频 0 │
└────────┴──────┴──────┴──────┘

  gpt-4o                       ✓
  gpt-4o-mini                  ✓
  gpt-image-1                  ✓
  ...

[＋ 手动添加]        [拉取模型]
```

- 切到哪个标签，就只显示那一类
- 手动添加时先选类型
- 「拉取模型」拉回来的东西默认进「文字」标签，**类型猜错的可以当场改**

---

## 4. 拉取抽屉：类型是「可点的标签」

很多站子的 `/models` 只给一串 ID，不给类型。所以：

```
拉取模型（雾港代理）
[搜索]

gpt-4o                     [文字]   ← 点一下 → 生图 → 语音 → 视频
gpt-image-1                [生图]
whisper-1                  [语音]
sora-1                     [视频]
some-unknown-model         [文字]

[添加 4 个]
```

类型先用关键词猜，猜错了点标签改。
保存时按标签分别写进 `kind`。

### 自动猜的规则（第一版）

| 关键词 | 猜成 |
|---|---|
| gpt / claude / gemini / deepseek / qwen / llama / mistral / glm / kimi | 文字 |
| dall-e / flux / stable-diffusion / sd / image / seedream / kolors / wanx | 生图 |
| tts / whisper / speech / audio / voice / cosyvoice | 语音 |
| sora / veo / kling / runway / pika / hailuo / video | 视频 |
| 认不出来 | 文字（并标一个「未确认」） |

> 认不出来时默认文字，是因为绝大多数站子只卖文字模型。
> 生图站如果只给 `flux-1.1-pro` 这种名字，能猜中。

## 5. 角色里：专属模型

角色档案 → 更多设置：

```
更多设置
  开场白
  示例对话
  专属模型
    聊天   跟随全局（gpt-4o）      ›
    生图   跟随全局（dall-e-3）    ›
    语音   跟随全局（未设置）      ›
```

点进去还是同一个选择抽屉，只是只列这一类。
没选就是「跟随全局」；选了就在这个角色身上覆盖。

---

## 6. 三个需要你拍板的点

1. **一个模型只归一类**，行不行？
   比如 gpt-4o 既聊天也能看图，第一版只把它当「文字」。
   真要兼用，再加「副类型」，不然界面会变复杂。

2. **主模型分四类**（聊天 / 生图 / 语音 / 视频）够不够？
   要不要再加「看图 / 向量」之类？我建议第一版就四类。

3. **拉取时自动猜 + 点标签改**，这个交互你接受吗？
   还是你想「先全部拉进来，再去模型管理里一个个归类」？

---

## 7. 跟照片的关系

角色档案里的「人物形象参考」已经支持：
- 多张照片
- 每张一个提示词（生图用）

以后接生图时，就是：
```
角色形象参考（照片 + 提示词）
        +
生图主模型（或角色专属生图模型）
        ↓
生成新的角色图 / 表情 / 场景图
```

这一版只存提示词，不接生成。
