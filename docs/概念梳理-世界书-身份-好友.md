# 概念梳理：小世界、世界书、身份、好友

> 2026-10-31 · 第三版（最终口径）
>
> **一句话：小世界决定「谁和谁在同一个地方」，模式决定「他们要不要互相影响」，身份决定「你是谁」。**

---

## 0. 五个抽屉

| 抽屉 | 是什么 | 例子 |
|---|---|---|
| **小世界** | 一套设定 + 一组角色 | 小世界1 |
| **模式** | 角色各过各的，还是同一个时空 | 角色独立 / 角色可关联 |
| **角色** | 演员：档案卡 + 自己的世界书 + 记忆 | 男朋友陈默 |
| **身份** | 你在这个小世界里是谁 | 你是他女友 / 你是他同事 |
| **关系** | 谁认识谁、是不是好友、多熟（只存在于「可关联」） | 哥哥和男朋友是好兄弟 |

小世界默认叫 **小世界1、小世界2**，新建时名字框预填好，懒得起名直接创建。

> **愿望机里没有「NPC」这个概念。**
> 角色卡正文里提到的人（哥哥、室友、前女友），就只是卡里的一段文字。
> 没有专门的 NPC 列表、没有 NPC 设置页、不建 NPC 表。
> 提到谁，模型就从卡里读到谁；没提到，就没有。

---

## 1. 小世界的两种模式

### 1.1 角色独立

**每张角色卡自己跑一条线。**

- 角色1 和角色2 的卡上都写了「我们认识」→ 在他们各自的故事里，对方确实存在
- 但 **角色1 线里的角色2** 和 **角色2 线里的角色2** 是两个人，互不影响
- 小世界里其他角色卡：**完全不读、不出现、不产生任何关系**
- 角色1 的线里，只读：**角色1 自己的卡 + 角色1 挂的世界书 + 小世界的设定**
- 卡里提到的人不是「另一个角色」，只是这张卡的一部分文字，不关联到别的卡

### 1.2 角色可关联

**同一个时空，多张角色卡一起生活。**

- 角色之间可以互相认识，也可以互不认识
- 认识的话，事情会互相传（见 `世界观与记忆设计.md`）
- 不认识就是陌生人，谁也不影响谁
- 这里也不需要 NPC 系统：卡里提到的人仍然只是文字

### 1.3 模式可以改

可以，但不删数据。改模式只影响**以后**怎么算关系：
可关联 → 独立：跨角色同步停止；独立 → 可关联：开始同步。
**已经写下的记忆不会消失。**

## 2. 世界书：只挂在角色身上

- **世界书只对挂了它的角色生效。** 没挂 = 不注入。
- 小世界可以放一个**书库**（方便挑），但默认空、默认不挂。
- 新建角色**不自动挂**任何书。
- 世界设定是**独立的一段文字**，不进世界书。
- 角色独立模式下，只读这个角色自己挂的书 + 小世界设定；别的角色挂的书完全不读。

> 「世界书作用在角色身上」彻底成立：**谁挂谁生效。**

### 顺便分清：世界书 / 正则 / 预设

| 名字 | 干什么 |
|---|---|
| 世界书 | 决定**往里加什么**（提到「校队」才补一段设定） |
| 正则 | 决定**把文字改成什么**（去掉星号、替换称呼） |
| 预设 | 决定**整段提示词怎么排** |

第一版只做世界书。机制参考 [Foreverse 世界书规范](https://foreverse.app/zh/docs/worldbook)。

## 3. 角色卡：档案样式

```
┌─────────────────────────────┐
│  ┌─────────┐   名字          │
│  │ 拍立得   │   一句话简介     │
│  │ 照片     │   和我的关系     │
│  └─────────┘   标签           │
├─────────────────────────────┤
│ 基本信息 + 人设（合成一块）    │
│ 名字 / 昵称 / 关系 / 人物信息   │
│ 性格 / 场景                    │
├─────────────────────────────┤
│ 世界书（挂了哪些）             │
├─────────────────────────────┤
│ 记忆                          │
├─────────────────────────────┤
│ 开场白（0 / 1 / 多个 IF）      │
└─────────────────────────────┘
```

- 照片：1:1、3:4、4:3、9:16；可拖动 + 缩放裁切；拍立得白框
- 照片是内容可以彩色；卡片的框和字仍然黑白灰
- 卡里提到的人写在「人物信息 / 性格 / 场景」里，**不单独设 NPC 栏**

## 4. 身份：一个世界可以有多个「你」

- 身份 = 名字、头像、设定、和角色的关系
- 一个小世界可以存多个身份
- **每个身份有自己的聊天记录和记忆，是一份独立的存档**
- 切走 = 这份存档先放那儿；切回来 = 接着上次聊，不用重来

**角色独立**：
- 每个角色可以绑一个身份，互不干扰

**角色可关联**：
- 同一时间，只能用一种身份面对这个小世界里的所有角色
- 换身份 = 角色们当你是另一个人；但旧身份的存档还在，随时能切回去

## 5. 开场白和好友，是两件事

| 问题 | 是什么 | 存在哪 |
|---|---|---|
| 认不认识？ | 世界设定 / 关系 | 关系数据 |
| 是不是好友？ | 好友状态 | 关系数据 |
| 从哪一句开始？ | 开场白 | 角色卡 |

关系状态机：

```
陌生人 ──你申请──▶ 待通过 ──对方同意──▶ 好友
   ▲                   │                  │
   └─── 对方拒绝 ◀──────┘                  │
                                           │
                        删除 / 拉黑 ◀───────┘
```

- 已经是好友：点聊天直接开始，用开场白
- 陌生人：按钮是「加好友」，走申请；同不同意看性格
- 对方也可以主动申请
- 删了又求复合：就是这条线再走一遍

开场白数量：

| 数量 | 聊天开始时 |
|---|---|
| 0 个 | 空白开场，角色说第一句 |
| 1 个 | 直接用它 |
| 多个 | 先选「从哪个情景开始」，选完才进聊天（IF 线） |

## 6. 统一之后，长这样

```
小世界（默认名 小世界1、小世界2）
├─ 设定（一段文字）
├─ 模式：角色独立 / 角色可关联
├─ 书库（可选，默认不挂）
├─ 身份（可多个，每个一份存档）
├─ 时间线（只有「可关联」才需要）
│  ├─ 角色（档案 + 自己的世界书 + 记忆）
│  └─ 关系（认识 / 好友 / 多熟）
```
