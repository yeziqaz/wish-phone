# 概念梳理：小世界、世界书、身份、好友

> 2026-10-31 · 第二版（按用户 10-31 晚的修正重写）
>
> **一句话：小世界决定「谁和谁在同一个地方」，模式决定「他们要不要互相影响」。**

---

## 0. 先分清六个抽屉

| 抽屉 | 是什么 | 例子 |
|---|---|---|
| **小世界** | 一套设定 + 一组角色 | 现代都市 |
| **模式** | 这个小世界里，角色是各过各的，还是同一个时空 | 角色独立 / 角色可关联 |
| **角色** | 演员：档案卡 + 自己的世界书 + 记忆 | 男朋友陈默 |
| **NPC** | 只从角色卡的「人物关系」里长出来的人 | 陈默的室友老周 |
| **身份** | 你在这个小世界里是谁 | 你是他女友 / 你是他同事 |
| **关系** | 谁认识谁、是不是好友、多熟 | 哥哥和男朋友是好兄弟 |

小世界默认叫 **小世界1、小世界2**，新建时名字框里会预填好，懒得起名直接创建就行。

---

## 1. 小世界的两种模式（建的时候选）

### 1.1 角色独立

**每张角色卡自己跑一条线。**

- 角色1 和角色2 的卡上都写了「我们认识」→ 他们确实认识
- 但 **角色1 线里的角色2** 和 **角色2 线里的角色2** 是两个人，互不影响
- 小世界里其他角色卡，默认**不出现、不产生任何关系**——不是 NPC，直接忽略
- 角色1 线里，角色2 想出场，只有一个办法：**角色1 的卡里「人物关系」写了角色2**

这条是单向的：

| 谁提到了谁 | 结果 |
|---|---|
| 角色1 的卡写了角色2 | 角色2 可以在角色1 的线里当 NPC |
| 角色2 的卡没写角色1 | 角色1 **不能**在角色2 的线里出场 |
| 两张卡互相都写了 | 各自线里都有对方的 NPC 版本，但还是两个人 |

> 为什么是单向：人物关系是「这个角色眼里的世界」，不是双向合同。
> 角色2 不认识角色1，那在角色2 的故事里，角色1 本来就不该出现。

### 1.2 角色可关联

**同一个时空，多张角色卡一起生活。**

- 角色之间可以互相认识，也可以互不认识
- 认识的话，事情会互相传（就是之前设计的记忆同步）
- 不认识就是陌生人，谁也不影响谁
- NPC 仍然是每个角色卡自带的，不必单独拎出来

### 1.3 模式可以改吗

可以，但不删任何数据。改模式只影响**以后**怎么算关系：
从「可关联」改「独立」，角色之间的同步就停了；反过来就开始同步。
**已经写下的记忆不会自己消失。**

## 2. NPC 只有一种来源

**NPC = 角色卡「人物关系」里写的人。** 没有第二种来源。

- 不单独建 NPC 表，不单独管 NPC 列表
- 有就是有，没有就是没有
- 人物关系里写：名字、和 TA 的关系、一段描述
- 如果这个名字正好对上同一个小世界里的另一张角色卡，可以**借用那张卡的长相/人设**来演——
  但演出来的仍然是「角色1 线里的角色2」，有自己的状态，和角色2 自己的线无关
- 对不上，就是一个纯粹的 NPC，不影响任何别的角色

> 这条解决了你担心的「把别人当 NPC」：**只有卡里写了，才算 NPC。**
> 没写的人，在小世界里就是空气。

---

## 3. 世界书：只挂在角色身上

上一版我建议「小世界的书默认继承给角色」，你否了。现在改成：

- **世界书只对挂了它的角色生效。** 没挂 = 不注入。
- 小世界可以放一个**书库**（方便你挑），但**默认不挂到任何角色**。
- 角色可以挂多本；也可以挂别的角色用过的书。
- 新建角色时**不自动挂**任何书。
- 世界设定是**独立的一段文字**，不再塞进世界书。

这样「世界书作用在角色身上」就彻底成立了：**谁挂谁生效，不挂就没有。**

> 以后如果嫌每次手动挂麻烦，可以加一个「复制到新角色」的按钮，
> 但那是手动动作，不是默认行为。

### 顺便分清：世界书 / 正则 / 预设

| 名字 | 干什么 |
|---|---|
| 世界书 | 决定**往里加什么**（提到「校队」才补一段设定） |
| 正则 | 决定**把文字改成什么**（去掉星号、替换称呼） |
| 预设 | 决定**整段提示词怎么排** |

第一版只做世界书。机制参考 [Foreverse 世界书规范](https://foreverse.app/zh/docs/worldbook)。

## 4. 角色卡：档案样式

```
┌─────────────────────────────┐
│  ┌─────────┐   名字          │
│  │ 拍立得   │   一句话简介     │
│  │ 照片     │   和我的关系     │
│  └─────────┘   标签           │
├─────────────────────────────┤
│ 基本信息 + 人设（合成一块）    │
│ 名字 / 性别 / 年龄 / 身份      │
│ 性格 / 背景 / 说话方式         │
├─────────────────────────────┤
│ 人物关系（NPC）               │
├─────────────────────────────┤
│ 世界书（挂了哪些）             │
├─────────────────────────────┤
│ 记忆                          │
├─────────────────────────────┤
│ 开场白（0 / 1 / 多个 IF）      │
└─────────────────────────────┘
```

- 照片：1:1、3:4、4:3、9:16；可拖动 + 缩放裁切；拍立得白框
- 照片是内容可以彩色；卡片的框和字仍然黑白灰
- 「人物关系」就是 NPC 区：名字、关系、描述、（可借用的角色卡）

## 5. 身份：一个世界可以有多个「你」

- 身份 = 名字、头像、设定、和角色的关系
- 一个小世界可以存多个身份

**角色独立**：
- 每个角色可以绑一个身份，互不干扰
- 角色1 用身份A、角色2 用身份B，完全没问题

**角色可关联**：
- 同一时间，**只能用一种身份**面对这个小世界里的所有角色
- 换身份 = 相当于重开：角色们当你是另一个人
- 旧身份的数据怎么办？我建议**保留成另一个存档**，随时能换回去（等你拍板）

## 6. 开场白和好友，是两件事

| 问题 | 是什么 | 存在哪 |
|---|---|---|
| 认不认识？ | 世界设定 / 关系 | 关系数据 |
| 是不是好友？ | 好友状态 | 关系数据 |
| 从哪一句开始？ | 开场白 | 角色卡 |

关系状态机：

```
陌生人 ──你申请──▶ 待通过 ──对方同意──▶ 好友
   ▲                   │                  │
   └─── 对方拒绝 ◀──────┘                  │
                                           │
                        删除 / 拉黑 ◀───────┘
```

- 已经是好友：点聊天直接开始，用开场白
- 陌生人：按钮是「加好友」，走申请；同不同意看性格
- 对方也可以主动申请
- 删了又求复合：就是这条线再走一遍

开场白数量：

| 数量 | 聊天开始时 |
|---|---|
| 0 个 | 空白开场，角色说第一句 |
| 1 个 | 直接用它 |
| 多个 | 先选「从哪个情景开始」，选完才进聊天（IF 线） |

## 7. 统一之后，长这样

```
小世界（默认名 小世界1、小世界2）
├─ 设定（一段文字）
├─ 模式：角色独立 / 角色可关联
├─ 书库（可选，默认不挂）
├─ 身份（可多个）
├─ 时间线（只有「可关联」才需要）
│  ├─ 角色（档案 + 人物关系 / NPC + 自己的世界书 + 记忆）
│  └─ 关系（认识 / 好友 / 多熟）
```

## 8. 还需要你拍板的

1. **换身份算重开**：旧身份的记忆留成存档，还是直接清掉？
2. **人物关系对角色卡**：NPC 名字和另一张卡重名时，自动借用那张卡，还是要你手动选「关联到角色卡」？
3. **角色独立**：小世界里其他角色卡的「世界书 / 记忆」是不是完全不读？（按你的说法是，确认一下）
