# 概念梳理：世界书、身份、好友、开场白

> 2026-10-31 · 回答「思绪乱了」的那一次
>
> **一句话：你不是缺功能，你是缺一把尺子 —— 什么时候该新建什么。**

---

## 0. 先给你一把尺子

你现在的混乱来自一件事：**「世界」被你同时用来指三样东西** ——
设定、角色名单、以及「你是谁」。

把这三样拆开，问题就没了。以后想加东西，先查这张表：

| 你想要的 | 用什么 | **不要**用什么 |
|---|---|---|
| 男朋友、哥哥、闺蜜互相认识 | 一个世界，三个角色 | 不要建三个世界 |
| 同一个世界，男朋友换人 | 一条新时间线 | 不要复制整个 App |
| 同一个角色，你是他女友 / 你是他同事 | 两个身份 | 不要建两个世界 |
| 同一个角色，从初遇开始 / 从吵架后开始 | 两个开场白 | 不要建新世界 |
| 两个人这辈子不可能认识 | 两个世界 | — |
| 只是想让角色知道「他高中是校队」 | 一条世界书条目 | 不要改世界设定 |

**判断「要不要新建世界」只看一件事：**
这两拨人需不需要互相知道对方的事？
需要 → 同一个世界；不需要 → 两个世界。

## 1. 五个抽屉，一句话一个

| 抽屉 | 是什么 | 例子 |
|---|---|---|
| **世界** | 舞台：年代、城市、规则 | 现代都市，2026 年 |
| **世界书** | 舞台的补充说明，按条件才拿出来 | 提到「篮球」才补「他高中是校队」 |
| **角色** | 演员：档案卡 + 自己的世界书 + 记忆 | 男朋友陈默 |
| **身份** | 你在这个世界里是谁 | 你是他女友 / 你是他同事 |
| **关系** | 谁认识谁、是不是好友、多熟 | 哥哥和男朋友是好兄弟 |

### 世界书 ≠ 世界观（但可以长在一起）

- **世界观**是一段散文：这个世界是什么样。
- **世界书**是一堆条目：提到某个词，才把某段设定塞进提示词。
- 混在一起会乱，但**界面上可以让它们长成同一个东西**：
  世界设定 = 世界书里的**第一条「常驻」条目**，默认启用。

这样就同时满足你说的两句话：
「把世界书和世界观看作同一个东西」✅
「世界书是条目组成的」✅
——一个容器，一份条目列表，第一条永远是设定。

### 顺便分清：世界书 / 正则 / 预设

这三样经常被一起提，但干的是三件不同的事（参考
[Foreverse 世界书规范](https://foreverse.app/zh/docs/worldbook)）：

| 名字 | 干什么 | 一句话 |
|---|---|---|
| 世界书 | 决定**往里加什么** | 提到「校队」就补一段设定 |
| 正则 | 决定**把文字改成什么** | 去掉 `*动作*` 的星号、把「俺」换成「我」 |
| 预设 | 决定**整段提示词怎么排** | 系统提示词模板 + 生成参数 |

第一版只做世界书。正则和预设以后再说，**现在别碰**。

## 2. 逐条回你

### 2.1 铅笔图标（已经做了）

角色页顶部的**当前世界**胶囊右侧，多了一个铅笔。
点它直接进世界编辑，不用再跑设置。

### 2.2 世界书挂在哪

- **世界的书**：这个世界里所有角色**默认继承**。
  继承是「引用」不是「复制」—— 你改世界书，所有角色跟着变，这就是你要的「自动同步」。
- **角色的书**：角色自己挂的**优先**。可以再加别的书，也可以取消继承。
- **新建角色时**：自动把当前世界的书挂上。
- **冲突时**：同一个条目 / 同一个关键词，角色自己的赢。

所以顺序是：**角色身上的书为主，世界的书是默认加一层底。**

### 2.3 角色卡：档案 / 拍立得

你想要的是「档案」，不是「表单」。建议长这样：

```
┌─────────────────────────────┐
│  ┌─────────┐   名字          │
│  │ 拍立得   │   一句话简介     │
│  │ 照片     │   和我的关系     │
│  │         │   标签           │
│  └─────────┘                │
├─────────────────────────────┤
│ 基本信息 + 人设（合成一块）    │
│ 名字 / 性别 / 年龄 / 身份      │
│ 和我的关系 / 性格 / 背景 / 说话方式 │
├─────────────────────────────┤
│ 世界书（挂载了哪些）           │
├─────────────────────────────┤
│ 记忆（自动整理的 + 手动加的）   │
├─────────────────────────────┤
│ 开场白（0 个 / 1 个 / 多个 IF） │
└─────────────────────────────┘
```

照片：
- 底板比例先支持 **1:1、3:4、4:3、9:16**
- 照片可以**拖动 + 缩放**，自己决定裁哪里
- 拍立得白框、轻微旋转、下面可以手写一行名字
- 照片是内容，可以是彩色；**卡片的框和字仍然是黑白灰**

### 2.4 世界书条目的字段

标准做法（和酒馆兼容）大致是这些。第一版只露前四个：

| 字段 | 意思 | 第一版 |
|---|---|---|
| 名字 | 这条叫什么（给自己看） | ✅ |
| 内容 | 要注入的设定正文 | ✅ |
| 启用 | 开 / 关 | ✅ |
| 触发 | 常驻 / 关键词 | ✅ |
| 关键词 | 对话里出现才触发，可写多个别名 | 关键词模式才出现 |
| 插入位置 | 角色设定前 / 后 / 按深度插入 | 折叠 |
| 优先级 | 预算不够时谁先被丢 | 折叠 |
| 激活概率 | 命中了也只有 N% 会注入 | 折叠 |
| 扫描深度 | 只看最近 N 条消息 | 折叠 |
| 递归 | 条目内容能再触发别的条目 | 以后 |

> 为什么要「概率」：同一个设定每次都说，模型会腻；偶尔提一次更像真的。
> 为什么要「预算」：常驻条目太多会把上下文吃光，超出预算的会被静默丢掉。

### 2.5 开场白 + 好友（这里你其实混了三件事）

把这三件事拆开就不乱了：

| 问题 | 它是什么 | 存在哪 |
|---|---|---|
| 认不认识？ | 世界设定 / 关系 | 关系数据 |
| 是不是好友？ | 好友状态 | 关系数据 |
| 从哪一句开始？ | 开场白 | 角色卡 |

**开场白 ≠ 好友申请。** 一个是「内容」，一个是「门槛」。

关系状态机：

```
陌生人 ──user 申请──▶ 待通过 ──对方同意──▶ 好友
   ▲                    │                    │
   └──── 对方拒绝 ◀──────┘                    │
                                              │
                          删除 / 拉黑 ◀────────┘
```

- **已经是好友**：点聊天直接开始，用开场白。
- **陌生人**：按钮是「加好友」，走申请；对方同不同意看性格和设定。
  警惕心强的会拒，拒绝理由就是角色自己写的一句（「我不认识你，你加错人了吧」）。
- **对方主动**：也可以由角色发来好友申请，user 同意才开始。
- **删了又求复合**：就是「好友 → 删除 → 申请 → 通过」这条线，不用专门做功能。

开场白有几种：

| 数量 | 聊天开始时 |
|---|---|
| 0 个 | 空白开场，角色说第一句（模型生成） |
| 1 个 | 直接用它 |
| 多个 | 先选「从哪个情景开始」，选完才进聊天（IF 线） |

### 2.6 多个身份

- **身份** = 你是谁：名字、头像、设定、和这个角色的关系。
- 一个世界可以有**多个身份**，聊天时选一个；不用为此新建世界。
- 「一个世界一个身份」只是最常见的情况，不是规定。
- 单角色聊天也不用开一堆世界：世界里只有一个人就行；
  可以给一个「快速开始」，少点几步。

## 3. 统一之后，长这样

```
世界
├─ 世界书（可多条；第一条 = 世界设定，常驻）
├─ 身份（你是谁，可多个）
└─ 时间线（平行时空，默认一条「主线」）
   ├─ 角色（档案 + 自己的世界书 + 记忆）
   ├─ 关系（认不认识 / 好友状态 / 多熟）
   └─ 对话（角色 × 身份）
```

时间线负责「故事走向不同」，身份负责「你是谁不同」，世界书负责「知道什么」。
三件事各管各的，就不会再互相打架。

---

## 4. 我建议的顺序

| 步骤 | 做什么 | 为什么这个顺序 |
|---|---|---|
| 1 | **角色卡档案化**：拍立得照片、裁剪、信息合并 | 你最在意界面；而且不依赖聊天 |
| 2 | **聊天（T6）** + 开场白 | wuli 能说话，后面所有东西才有地方验证 |
| 3 | **世界书**：条目编辑 + 世界/角色挂载 + 注入 | 注入要有聊天才测得出来 |
| 4 | **身份** + 好友状态 | 聊天有了，才谈得上「加好友才能聊」 |
| 5 | **记忆同步** + 朋友圈 | 最后做，依赖前面全部 |

> 注意：世界书**界面**可以先做，但「到底有没有注入」必须等聊天做完才能验收。
> 所以我不建议先花大力气做世界书编辑器的花活。
