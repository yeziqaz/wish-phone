
「聊天室」「聊天APP 首页」「朋友圈」「我」「美化」五件互不相干的事，

**3. 桌面 APP 表硬编码在 `desktop.ts`**


## 二、你要的层级（我理解的）

```
手机
├─ 外壳（锁屏 / 桌面 / 状态栏）
│
├─ 全局设置
│   ├─ 数据储存
│   ├─ 世界书
│   └─ 服务商 / API / 模型
│
└─ APP
    ├─ 聊天APP
    │   ├─ 首页（消息 / 通讯录 / 朋友圈 / 我）
    │   ├─ 聊天室（每个角色一间）
    │   └─ 美化
    │       ├─ 聊天室作用域（气泡 / 头像挂件 / 背景 / 字体）
    │       └─ 聊天APP作用域（界面配色 + 上面全部）
    ├─ 角色APP
    └─ 以后：转账、日记、相册…
```

**核心原则：一个 APP 一个目录，APP 内部再分层。** 三件事必须做到：

1. **能按名字找到** —— 想改「气泡圆角」就去 `apps/chat/beauty/`，不用翻 `chat.ts`
2. **美化完全独立** —— 它对聊天室零依赖（已核实：美化内部零反向引用）
3. **加 APP 不改别人** —— 新增 APP 只往 APP 注册表加一行

## 四、我要你决定的四件事

### 决定 1：改造幅度

| 方案 | 内容 | 风险 | 耗时 |
|---|---|---|---|
| **A. 只拆美化**（最小） | 美化 6 文件搬进 `apps/chat/beauty/`，其余不动 | 低 | 快 |
| **B. 拆聊天APP**（推荐） | 美化独立 + 首页/聊天室分开 + 拆 `chat.ts` | 中 | 中 |
| **C. 全量重整** | B + 外壳/APP注册表 + 合并 providers/api | 高 | 慢 |

**我推荐 B**，理由：

- A 解决不了「`chat.ts` 1207 行」这个真正的问题
- C 里的 `providers`/`api` 合并是另一个独立任务（5388 行两套并存），
  和「结构清晰」不是同一件事，混在一起会互相拖累
- B 做完之后，C 的每一步都变简单了

### 决定 2：`chat.ts` 1207 行拆到什么程度

它现在同时干五件事：视图渲染、软键盘适配、气泡生成、AI 调用+逐字回放、抽屉。

| 选项 | 拆成 |
|---|---|
| 保守 | `room.ts`（主）+ `viewport.ts`（键盘）+ `stream.ts`（逐字） |
| 激进 | 上面 + `bubbles.ts`（气泡）+ `drawer.ts`（抽屉），`room.ts` 降到 ~350 行 |

**我推荐激进**：你说了「以后功能越做越多」，现在拆比以后拆便宜。

### 决定 3：`providers` 和 `api` 怎么办

两个都在做「服务商 / 模型 / 分配」，5388 行。

| 选项 | 说明 |
|---|---|
| 本轮不动 | 只在文档里记一笔「待合并」 |
| 本轮合并 | 风险高，可能引入 bug |

**我推荐本轮不动**，但要在 `main.ts` 和文档里明确标注「`providers` 是过渡层」，
否则半年后又没人记得哪个是活的。

### 决定 4：目录名

`src/apps/` 里放 `chat` / `character` / `settings`，
那"全局设置"是 `src/settings/` 还是 `src/apps/settings/`？

- 若 全局设置 也算一个 APP（从桌面能点进去）→ 放 `src/apps/settings/`
- 但世界书/服务商是"手机的设置"，不是"APP"

**我推荐**：`src/apps/` 只放**桌面上的 APP**，
全局设置放 `src/settings/`（顶层），因为它不属于任何 APP，属于手机本身。

## 五、这次重整**不会**改变的事

- 不改任何一行业务逻辑
- 不改数据库结构（不加迁移）
- 不改任何视觉
- 不改路由 URL（用户书签不会失效）

**纯搬运 + 拆分 + 改 import 路径。**
每做完一步都跑 `tsc + build + test`，测试数量必须始终 133 不变（除非故意调）。

## 六、怎么保证「没搞坏」

1. 每一步都跑：`npx tsc --noEmit && npm run build && npm test`
2. 测试数必须保持 **133 / pass 133**
3. 每一步都在手机上验证一次：桌面→聊天→聊天室→发一条消息→返回
4. 不一次搬完，按「美化 → 首页 → 聊天室」分批，每批之间可回退
