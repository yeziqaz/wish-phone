# 手机排版参考（给写界面的人看）

> 这是 `mobile-ui-craft` 技能的展开版。规则以 `STYLE.md` 为准，这里只给「怎么排」。

## 一、页面骨架

```
┌──────────────────────────┐
│ 安全区                    │
│ [←]  标题            [+]  │ 44
│                           │ 12
│ 内容                      │
│                           │
│                           │
│ [    主按钮 44    ]       │ 底部，避开安全区
│ 安全区                    │
└──────────────────────────┘
```

- 左右留白 20~24
- 顶栏 44，标题 17~20
- 正文从顶栏下 12~16 开始
- 底部主按钮和内容之间至少 24

## 二、设置目录

```
┌──────────────────────────┐
│ [图标] 标题              > │ 60
│        副标题              │
├──────────────────────────┤
│ [图标] 标题              > │ 60
└──────────────────────────┘
```

- 图标 40×40，圆角 10
- 行高 60；副标题 12px `--ink-3`
- 整组一个外框，行间一条线
- 一行一个开关的，不要把开关做成按钮

## 三、角色/内容卡

```
┌──────────────────────────┐
│ [头像52] 名字            > │ 72
│          一句话描述        │
│          关系 · 标签       │
└──────────────────────────┘
```

- 卡内边距 16；卡间距 8
- 标题 15~17；描述 12~13，最多两行
- 右侧箭头 18，颜色 `--ink-3`
- 不要给每张卡加大阴影

## 四、表单

- 标签在上，13px `--ink-2`
- 输入框高 44，圆角 10
- 提示在下方，12px `--ink-3`
- 字段间距 16
- 两个短字段才并排；长中文标签一律单列

## 五、底部抽屉

- 顶部抓手 36×4
- 标题 17
- 列表行 52~56
- 底部按钮 44，避开安全区

## 六、照片带

- 容器高 `clamp(220px, 42vh, 320px)`
- `scroll-snap-type: x mandatory`
- 图片 `object-fit: contain`
- 位置提示 `1 / 3`，12px
- 加图按钮放在下方，不要塞进最后一张

## 七、判断「好不好看」的三个问题

1. **眯眼看**：最跳的地方是不是主行动？
2. **盖住文字看**：灰块之间的关系清不清楚？
3. **只看第一屏**：能不能知道这是干什么的、下一步点哪？
