## 六、从这批图里提炼的「黑白灰造层次」五种手法

没有颜色可用时，这些图靠五件事建立视觉层次——这是本项目配色系统的核心方法论：

1. **反色块**：黑底白字 vs 白底黑字，用来区分主次动作（实心"确定" vs 描边"取消"）
2. **纹理填充**：斜线网点、棋盘格、交叉线代替灰色填充，比纯灰更有质感且不吃色彩
3. **描边线框**：1px 边框 + 大量留白表达结构，最轻
4. **软阴影**：同色系靠光影浮起（新拟物），柔和但对比弱、低端机性能开销大
5. **色阶灰**：纯黑 → #333 → #666 → #999 → #E5E5E5 → #FAFAFA，靠字号/字重/间距制造层级

> ✅ **已决策**：走「多级灰 + 描边线框」路线（`28596`/`28585`）。毛玻璃**不作为默认**，只列为可选增强（低端机 `backdrop-filter` 开销大）。
> 配套决策：图标 = 桌面实心 + 内页线性；色彩 = 黑白灰 + 一个可替换强调色变量；纹理 = 少量点缀。
> 落地文件见 [`../tokens.css`](../tokens.css) 与 [`../STYLE.md`](../STYLE.md)。

## 八、从第二批新增的两条规则

### 规则 A · 灰阶四段法（来自 `28576`）

同一组件用四种底面灰度表达四种状态，**不引入新颜色**：

| 档位 | 用途 | 对应令牌 |
|---|---|---|
| ① 纯白 / 浅灰 | 未选中、普通卡片 | `--surface` |
| ② 中浅灰 | 次级、禁用、凹槽 | `--surface-2` |
| ③ 深灰 | 选中、悬浮强调 | 深色 `--surface-2` ↔ 浅色 `--ink-2` 系 |
| ④ 反色 | 主行动、当前项 | `--inverse-bg` / `--inverse-ink` |

### 规则 B · 点阵用于"进度/成就"表达（来自 `28575`）

点阵不是纯装饰——当语义是"一格一格"的（进度、打卡、年度回顾）时，用点阵比进度条更贴黑白灰语言。这是纹理白名单之外**唯一**允许的扩展场景。

### 规则 C · 同一个信息不在两处当主角

来自 `28235` 的教训：它把时钟做成各种尺寸重复出现，好看但信息冗余。

我们的处理是**让"时间"在锁屏当主角、在桌面当配角**：

| 位置 | 字号 | 颜色 | 角色 |
|---|---|---|---|
| 锁屏 | `clamp(56px, 21vw, 92px)`，`--fw-medium` | `--ink` | 主角 |
| 桌面顶部 | `--fs-sm` | `--ink-3` | 配角（状态栏） |

同一个数据，一处大声、一处小声，**绝不并列出现两个同等分量的时钟**。
