# 愿望机 · 视觉规范（已定稿）

> 本文件是**约束**，不是建议。所有界面开发照此执行；要改规则，先改这里。

## 一、四个已定基调

| 维度 | 决定 | 含义 |
|---|---|---|
| 黑白灰气质 | **多级灰 + 描边线框** | 靠 1px 描边、灰阶、留白分层；不靠大色块，不靠阴影堆叠 |
| 图标 | **桌面实心 + 内页线性** | 桌面图标远看要认清（实心）；App 内页要精致（线性 stroke 1.75px） |
| 色彩 | **黑白灰 + 一个可替换强调色变量** | 现在强调色 = 黑；将来换色卡只改 `--accent` 一个值 |
| 纹理 | **少量点缀** | 只允许出现在白名单位置，主体界面必须干净 |

## 二、色值必须走变量

组件代码里**禁止出现裸色值**（`#111`、`rgb(...)` 一律不许）。全部引用 `tokens.css` 的语义变量：

```
底色   --bg --surface --surface-2
描边   --line --line-strong
文字   --ink --ink-2 --ink-3 --ink-4
强调   --accent --accent-ink --inverse-bg --inverse-ink
语义   --success --success-bg --warning --warning-bg --info --info-bg --danger --danger-bg
```

深色模式同理，一套变量两套值，靠 `[data-theme="dark"]` 切换。**深色模式不是简单反相**，灰阶要重新分配（见 tokens.css）。

### 灰阶语义约定（不要混用）

灰色的作用是**分工**，不是"深浅随便挑"。文字有且只有四档：

| 变量 | 角色 | 用在哪 |
|---|---|---|
| `--ink` | 主要文字 | 标题、正文 |
| `--ink-2` | 次要文字 | 说明、时间、辅助信息 |
| `--ink-3` | 辅助行文 | 小字提示。**这是正文级，白底对比度必须 ≥ 4.5:1** |
| `--ink-4` | 占位 / 不可用 | 输入框 placeholder、禁用态。**只用于不需要读清的地方** |

底色与描边：

| 变量 | 用在哪 |
|---|---|
| `--bg` | 页面底，最底层 |
| `--surface` | 卡片、面板、输入框的底 |
| `--surface-2` | 凹槽、hover、分组底 —— 表示"比卡片低一层" |
| `--line` | 常规分隔与卡片边框 |
| `--line-strong` | 可点击控件的边界（按钮、输入框），必须比 `--line` 明显 |

### 强调色：少用才显眼

强调色（`--accent`）只有一个作用：**告诉用户这一步该点哪里**。

✅ 只允许出现在四个地方：
1. 主行动按钮（每屏最多一个）
2. 链接
3. 输入框的焦点边框
4. 选中态（勾选、开关打开、当前 tab）

❌ 禁止：
1. **次要按钮用强调色** —— 「取消」「返回」必须白底加边框，把重点让给主按钮
2. 装饰性地涂在图标、标题、分隔线上
3. 同屏两个主按钮（两个一样重 = 用户不知道该点哪个）

判断标准：一屏截图眯眼看，**最跳的那个地方，应该正好是唯一的主行动**。

### 语义色：只做状态反馈

四种状态各一浅一深，**浅的做底、深的写字**：

| 变量 | 用在哪 |
|---|---|
| `--success` | 保存成功、连接正常 |
| `--warning` | 存储快满了、有风险但不阻断 |
| `--info` | 中性提示 |
| `--danger` | 删除、连接失败、填错了 |

❌ 禁止拿来装饰、禁止同时出现三种以上、**彩色底上不许放灰字**（改同色系的深色字）。

### 对比度底线

| 文字 | 最低对比度 |
|---|---|
| 正文（15px 及以下） | **4.5:1** |
| 大字（20px 以上或加粗） | 3:1 |
| 纯装饰的占位符 | 3:1 |

拿不准就把颜色调深一档 —— 宁可灰得发黑，不要浅到看不清。

### 几个不能犯的坑

1. **一屏里鲜艳色超过两个** → 抢眼，主次全丢
2. **次要按钮用强调色** → 两个按钮一样重
3. **大面积纯黑底**（`#000`）→ 看久了累眼，用很深的灰
4. **彩色底上放灰字** → 发闷看不清，改同色系深色
5. **深色模式直接反相** → 阴影会消失，得改用浅一点的描边分层

## 二·五、按钮：六种变体，主要按钮一屏只出现一次

按重要程度从高到低，**每种只做一件事**：

| 类名 | 样子 | 用在哪 |
|---|---|---|
| `.btn--primary` | 强调色底 | **一屏唯一**的主行动：保存、提交、完成 |
| `.btn--secondary` | 浅灰底、无边框 | 和主要并排的备选：取消、返回 |
| `.btn`（默认） | 白底 + 边框 | 常规操作，白底上边界更清楚 |
| `.btn--ghost` | 无底无边 | 工具栏、卡片里的低优先级操作 |
| `.btn--danger` | 红底白字 | 删除、清空这类**不可逆**操作 |
| `.btn--link` | 文字 + 下划线 | 像文字一样轻的跳转 |

规则：

1. **主要按钮一屏只出现一次。** 两个一样重 = 用户不知道该点哪个。
   结果一出来就把上一步的主按钮降级（去掉 `--primary`）。
2. **次要按钮永远不许用强调色。** 取消、返回都是白底或浅灰底。
3. **红色只留给危险操作**，不许拿来强调普通按钮 ——
   否则真正危险的时候，就没人当回事了。
4. **危险按钮的文案要写清动作**（「删除」而不是「确定」），且必须二次确认。
5. **只有图标的按钮**：宽高相等，必须带 `aria-label`，热区仍要 44×44。
6. **按钮组共享边框**：相邻按钮之间只有一条线，只有两端保留圆角（见 `.segmented`）。
7. **不要用 `div` 假装按钮**，原生 `<button>` 自带键盘和焦点支持。

### 六种状态

| 状态 | 表现 |
|---|---|
| 默认 | 什么都没发生 |
| 悬停 | 背景变化一级，**包在 `@media (hover: hover)` 里**，手机点完不会卡住 |
| 按下 | 缩小（我们的做法是 `.jelly` 果冻反馈，见 §五） |
| 聚焦 | `:focus-visible` 才出焦点环，鼠标点击不出 |
| 禁用 | 透明度降到 50%，`pointer-events: none` |
| 加载 | **按钮宽度不能变**，只换文字/加转圈 |

## 二·六、排版：层级靠字号、字重、行高来分

### 字号只许用这几档

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-display` | 28px | 桌面大时钟、数字展示 |
| `--fs-title` | 20px | 页面标题 |
| `--fs-lg` | 17px | 列表标题、按钮 |
| `--fs-base` | 15px | 正文 |
| `--fs-sm` | 13px | 辅助说明 |
| `--fs-caption` | 12px | 角标、时间戳 —— **不许再往下调** |

同一块区域里的字号档位不要超过 3 种。

### 字重只用 400 / 500 / 600

一个界面里 2~3 种就够。**不要用 700 以上**，中文字体的大粗在小屏上会糊。

### 字距

- 20px 以上的标题：`--tracking-tight`（-0.02em），大标题收紧才不松垮
- 全大写的小字：`--tracking-wide`（0.04em）
- 正文不动

### 行高

- 正文 `--lh-base`（1.6）
- 标题 `--lh-tight`（1.25）

手机小屏上正文不要再往下压（1.5 以下中文会挤）；长文可以放到 1.7。

### 数字对齐

会变化的数字（时钟、统计、金额）加 `.tabular`（`font-variant-numeric: tabular-nums`），
位数变动时不会左右跳。

### 字体

只用系统字体（`--font-sans`），**不许引任何远程字体 CDN** —— 见 AGENTS.md §1。

## 二·七、触控面积

1. 可点面积**不小于 44×44px**。
2. 图标本身可以只画 16~24px，**周围补一圈透明区域**把热区撑到 44。
3. 相邻两个可点元素之间至少留 **8px**。

## 三、「反色块」的使用红线

反色块（黑底白字 / 深色模式下的白底黑字）是我们在无色彩条件下**最强的强调手段**，因此极其稀缺：

✅ 允许：
1. 每个页面**最多一个**主行动按钮（确定 / 发送 / 下一步）
2. 底部导航与顶栏的**选中态**
3. 需要拉开层级的强调 Header
4. 角色卡、封面的标题条

❌ 禁止：
1. 大面积正文背景
2. 同屏出现两个以上的反色块互相抢注意力
3. 用它代替"重要"来表达情绪

## 四、「纹理」白名单

纹理只在下面四个位置出现，其他任何地方用了都算违规：

1. 桌面壁纸底
2. 空状态插图背景
3. 角色卡 / 封面的装饰区
4. 反色块内部的点缀（如纯黑面板上的细斜纹）

三种可选纹理：`--tex-hatch`（斜纹）、`--tex-dots`（网点）、`--tex-grid`（细网格）。
**一张界面里最多出现一处纹理。**

## 五、动效：果冻反馈只碰 transform

按下快（80ms）、松开慢（650ms 带过冲），这是"手感"的来源。

**铁律：反馈层（transform / box-shadow）和美化层（background / border / color）不许抢同一个 CSS 属性。**
颜色渐变走 `--dur-normal` 的普通缓动，位移缩放走 `--ease-jelly`，两条 transition 各管各的。

必须尊重 `prefers-reduced-motion`。

## 六、触控底线

- 任何可点击元素的触控区 **不小于 44×44px**（`--tap-min`）
- 桌面图标容器固定 46px，内页线性图标 22px
- 不使用 12px 以下字号做正文

## 七、第一版组件清单（从参考图 `28580` 提取）

写组件时按这个清单来，**不做的功能不要提前写**：

| 类别 | 组件 |
|---|---|
| 基础 | 按钮（实心 / 描边 / 文字 / 危险 / 禁用）、图标按钮、标签胶囊、分隔线 |
| 输入 | 文本框、多行输入、搜索框、开关、单选、复选 |
| 展示 | 卡片、列表项、头像、徽标、进度条、步骤条、分页点 |
| 反馈 | 轻提示（Toast）、对话框（提示 / 成功 / 警告）、骨架屏、空状态 |
| 聊天 | 文字气泡（用户/角色）、图片气泡、时间戳、输入工具条 |
| 导航 | 底部导航栏、顶栏（返回 / 标题 / 操作）、抽屉 |

## 八、图标规范

- **桌面**：实心图标，24px 图形装在 46px 容器里，下方配 11px 标签
- **内页**：线性图标，`stroke-width: 1.75`，尺寸 20 / 22 / 24
- 同一功能在桌面和内页**必须是同一个图形的实心/线性两版**，不能换图形
- 推荐图标库：Lucide（线性，MIT）；需要实心时优先用同库的 filled 变体，或按同一套几何自绘
