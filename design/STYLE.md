# 愿望机 · 视觉规范（已定稿）

> 本文件是**约束**，不是建议。所有界面开发照此执行；要改规则，先改这里。

## 一、四个已定基调

| 维度 | 决定 | 含义 |
|---|---|---|
| 黑白灰气质 | **多级灰 + 描边线框** | 靠 1px 描边、灰阶、留白分层；不靠大色块，不靠阴影堆叠 |
| 图标 | **桌面实心 + 内页线性** | 桌面图标远看要认清（实心）；App 内页要精致（线性 stroke 1.75px） |
| 色彩 | **黑白灰 + 一个可替换强调色变量** | 现在强调色 = 黑；将来换色卡只改 `--accent` 一个值 |
| 纹理 | **少量点缀** | 只允许出现在白名单位置，主体界面必须干净 |

## 二、色值必须走变量

组件代码里**禁止出现裸色值**（`#111`、`rgb(...)` 一律不许）。全部引用 `tokens.css` 的语义变量：

```
--bg --surface --surface-2 --line --line-strong
--ink --ink-2 --ink-3 --inverse-bg --inverse-ink --accent --accent-ink --danger
```

深色模式同理，一套变量两套值，靠 `[data-theme="dark"]` 切换。**深色模式不是简单反相**，灰阶要重新分配（见 tokens.css）。

### 灰阶语义约定（不要混用）

| 变量 | 用在哪 |
|---|---|
| `--bg` | 页面底，最底层 |
| `--surface` | 卡片、面板、输入框的底 |
| `--surface-2` | 凹槽、hover、分组底 —— 表示"比卡片低一层" |
| `--line` | 常规分隔与卡片边框 |
| `--line-strong` | 可点击控件的边界（按钮、输入框），必须比 `--line` 明显 |
| `--ink` | 标题、正文主字 |
| `--ink-2` | 辅助说明、次要信息 |
| `--ink-3` | 占位符、禁用、时间戳 |

## 三、「反色块」的使用红线

反色块（黑底白字 / 深色模式下的白底黑字）是我们在无色彩条件下**最强的强调手段**，因此极其稀缺：

✅ 允许：
1. 每个页面**最多一个**主行动按钮（确定 / 发送 / 下一步）
2. 底部导航与顶栏的**选中态**
3. 需要拉开层级的强调 Header
4. 角色卡、封面的标题条

❌ 禁止：
1. 大面积正文背景
2. 同屏出现两个以上的反色块互相抢注意力
3. 用它代替"重要"来表达情绪

## 四、「纹理」白名单

纹理只在下面四个位置出现，其他任何地方用了都算违规：

1. 桌面壁纸底
2. 空状态插图背景
3. 角色卡 / 封面的装饰区
4. 反色块内部的点缀（如纯黑面板上的细斜纹）

三种可选纹理：`--tex-hatch`（斜纹）、`--tex-dots`（网点）、`--tex-grid`（细网格）。
**一张界面里最多出现一处纹理。**

## 五、动效：果冻反馈只碰 transform

按下快（80ms）、松开慢（650ms 带过冲），这是"手感"的来源。

**铁律：反馈层（transform / box-shadow）和美化层（background / border / color）不许抢同一个 CSS 属性。**
颜色渐变走 `--dur-normal` 的普通缓动，位移缩放走 `--ease-jelly`，两条 transition 各管各的。

必须尊重 `prefers-reduced-motion`。

## 六、触控底线

- 任何可点击元素的触控区 **不小于 44×44px**（`--tap-min`）
- 桌面图标容器固定 46px，内页线性图标 22px
- 不使用 12px 以下字号做正文

## 七、第一版组件清单（从参考图 `28580` 提取）

写组件时按这个清单来，**不做的功能不要提前写**：

| 类别 | 组件 |
|---|---|
| 基础 | 按钮（实心 / 描边 / 文字 / 危险 / 禁用）、图标按钮、标签胶囊、分隔线 |
| 输入 | 文本框、多行输入、搜索框、开关、单选、复选 |
| 展示 | 卡片、列表项、头像、徽标、进度条、步骤条、分页点 |
| 反馈 | 轻提示（Toast）、对话框（提示 / 成功 / 警告）、骨架屏、空状态 |
| 聊天 | 文字气泡（用户/角色）、图片气泡、时间戳、输入工具条 |
| 导航 | 底部导航栏、顶栏（返回 / 标题 / 操作）、抽屉 |

## 八、图标规范

- **桌面**：实心图标，24px 图形装在 46px 容器里，下方配 11px 标签
- **内页**：线性图标，`stroke-width: 1.75`，尺寸 20 / 22 / 24
- 同一功能在桌面和内页**必须是同一个图形的实心/线性两版**，不能换图形
- 推荐图标库：Lucide（线性，MIT）；需要实心时优先用同库的 filled 变体，或按同一套几何自绘
